Tutorial Introduction to Spatial Analysis and Cartography with R

uRos November 2026

Speaker

Kim Antunez

The database used in this practical session concerns the geolocation of road accidents in Paris. More specifically, it consists of the annual databases of bodily injury road traffic accidents, in particular the 2019 edition.

“For each bodily injury accident (i.e. an accident occurring on a road open to public traffic, involving at least one vehicle and resulting in at least one victim requiring medical care), information describing the accident is recorded by the law enforcement unit (police, gendarmerie, etc.) that intervened at the accident location. These records are compiled in a form called the bodily injury accident analysis bulletin. All of these forms constitute the national file of bodily injury road traffic accidents known as the “BAAC File”, administered by the French Interministerial Road Safety Observatory (ONISR).”

“A number of indicators derived from this database are certified by the Official Statistics Authority (order of 27 November 2019).”


You can download the raw databases here or use R to download them to your current directory:

# download the dataset
download.file("https://github.com/antuki/uros2026_spatialanalysis/raw/main/exercises/data.zip", 
              destfile = "data.zip")
# unzip
unzip("data.zip",exdir=".")

NoteQuestion 5

Perform at least one of the following geometric processing tasks:

  1. Create a polygon outlining Paris by aggregating the Paris iris (simple union)
  2. Create a 1 km buffer zone around it
  3. Extract the centroids of the iris
  4. Calculate the distances between the iris centroids
  5. Calculate Voronoi polygons around the iris centroids

Display the different layers created

TipHint

Use the functions st_union, st_buffer, st_voronoi, st_collection_extract, st_interection, st_join and st_centroid.

CautionSolution

# 3. Centroids

Exercise 3: ggplot2 maps

We want to create a map of the Paris arrondissements that combines the number of people involved in accidents and the share of those who were not injured.

NoteQuestion 1

Prepare the data for the map using the following steps:

  1. Load the ‘com75_shp’ map background (which contains the number of people involved in accidents, both total and uninjured, in each arrondissement) and create a variable called part_non_blesses corresponding to the share of uninjured people among accident victims in each arrondissement.
  2. Create a vector of the quartiles of the part_non_blesses variable.
  3. Create the color vector corresponding to the number of classes defined above.
  4. Add a variable called typo to ‘com.75’ indicating the arrondissement class according to the discretization contained in bks for the part_non_blesses variable.
TipHint

For creating bks and cols, use the quantile and RColorBrewer::brewer.pal functions. For creating the typo variable, you can use the cut function with the digit.lab = 2 and include.lowest = TRUE parameters.

CautionSolution 
library(sf)
# 1. Import the data and create the part_non_blesses variable
com.75 <- st_read("data/com_75.shp", quiet = TRUE)
com.75$part_non_blesses <- 100 * com.75$nbaccnb / com.75$nbacc

# 2. Define bks by quantile
bks <- quantile(com.75$part_non_blesses, na.rm = TRUE, probs=seq(0,1,0.25))

# 3. Define a color palette
library(RColorBrewer)
cols <- brewer.pal(length(bks)-1,"Greens")

# 4. Typo variable
library(dplyr)
com.75 <- com.75 |>
  mutate(typo = cut(part_non_blesses,
                    breaks = bks,
                    labels = paste0(
                      round(bks[1:(length(bks)-1)]),
                      " à ",round(bks[2:length(bks)])
                      ),
                    include.lowest = TRUE))

Exercise D: Grammar of graphics and ggplot2

Note

TipHint

Use the ggplot2::geom_barplot() function to create a bar chart. And implement the grammar of graphics in this specific case.

  1. Keep only the catv vehicles for which there are more than 100 people involved in accidents;
  2. Create a database with a prop column corresponding to the percentage distribution of accident severity grav (Killed, Hospitalized injured, Slightly injured and Uninjured) for each selected catv vehicle type from step 1.
  3. Make sure to convert the two variables to factor so that they are properly ordered
  • grav in the following order: c("Tué", "Blessé hospitalisé","Blessé léger","Indemne")
  • catv in the graph order corresponding to the increasing order of the share of uninjured people by vehicle category
  1. Create the graph (geom_barplot, scale_fill_manual, theme_bw, geom_text, labs)
CautionSolution 
# 1. Keep only vehicles with +100 people involved in accidents
vehic_plus100_accidents <- accidents.2019.paris %>% st_drop_geometry %>% 
  count(catv) %>% filter(n>100) %>% pull(catv)
# 2. Create databases with percentages
gg <- accidents.2019.paris %>%
  st_drop_geometry() %>% 
  filter(catv %in% vehic_plus100_accidents) %>% 
  mutate(catv_f = factor(catv)) %>% 
  mutate(grav_f = factor(grav, #3. properly ordered grav_f
                         levels = c(2,3,4,1),
